# 🎓 نظام الاستعلام الأكاديمي الذكي المتقدم - مدرسة النجاح باليعر

**مقدم للدكتورة:** د. مروة  
**طبيعة التكليف:** بناء واجهات ويب ديناميكية تعتمد بالكامل على قاعدة معرفة (Knowledge Base) بتنسيق `JSON`، مع دمج **خوارزميات الذكاء الاصطناعي (Greedy Algorithm)** لتحسين النتائج.

---

## 📌 1. نبذة عامة عن المشروع
هذا المشروع عبارة عن تطبيق ويب تفاعلي صُمم ليكون دليلاً أكاديمياً متكاملاً لـ **"مدرسة النجاح باليعر"**. 
يعتمد المشروع في تغذيته بالبيانات على ملف **Knowledge Base (JSON)** حصراً، بالإضافة إلى تضمين خوارزميات بحث وتحسين ذكية لترشيح البيانات بأفضل شكل ممكن.

---

## 🧠 2. خوارزميات الذكاء الاصطناعي المستخدمة (AI Algorithms)
نظراً لأن المشروع يتقاطع مع مفاهيم الذكاء الاصطناعي، تم تطبيق خوارزميتين أساسيتين لمعالجة البيانات:

### أ) خوارزمية البحث الخطي (Linear Search - O(N))
- **الاستخدام:** تُستخدم في "الاستعلام العادي".
- **الوظيفة:** عندما يختار المستخدم الصف، يقوم النظام بالبحث داخل شجرة الـ JSON بشكل خطي واستخراج المواد والمعلمين المطابقين وعرضهم مباشرة.

### ب) الخوارزمية الجشعة (Greedy Algorithm - Set Cover Problem) 🌟
- **الاستخدام:** تُستخدم في زر "التحسين الذكي".
- **الوظيفة:** عندما يختار المستخدم مجموعة كبيرة من المواد ويريد إيجاد **"أقل عدد ممكن من المعلمين لتغطية كل هذه المواد"** (وهي مشكلة كلاسيكية في علوم الحاسوب تُعرف بـ Set Cover).
- **كيف تعمل الخوارزمية (الخيار الجشع):**
  1. تقوم بالبحث عن المعلم الذي يغطي **أكبر عدد ممكن من المواد غير المغطاة**.
  2. تضيف المعلم للقائمة، وتحذف مواده من قائمة المواد المتبقية.
  3. تكرر العملية حتى يتم تغطية جميع المواد التي اختارها المستخدم.
  4. تطبع للمستخدم خطوات التفكير (Thinking Logs) لتثبت كيف اتخذت القرار.

---

## 🗂️ 3. هيكلة قاعدة المعرفة (Knowledge Base Structure)
تم بناء ملف `kb.json` ليكون شاملاً ويغطي **12 سنة دراسية كاملة** (من الأول الأساسي حتى الثالث الثانوي). وتمت هيكلة البيانات كالتالي:
1. **Educational Stages (المراحل الدراسية):** (الأساسية، الإعدادية، الثانوية)
2. **Grades (الصفوف):** كل مرحلة تحتوي على صفوفها الخاصة.
3. **Subjects (المواد والمعلمين):** يمتلك كل صف مصفوفة من المواد، وتحتوي كل مادة على:
   - `subject_name`: اسم المادة.
   - `teacher`: اسم المعلم.
   - `book`: اسم الكتاب المقرر.

---

## ⚙️ 4. آلية عمل الواجهة (User Interface Logic)
1. **القائمة المنسدلة (Dropdown):** بناء الخيارات وتصنيفها من الـ JSON.
2. **التوليد الديناميكي (Dynamic Checkboxes):** بناء Checkboxes ديناميكية تتطابق مع مواد الصف المحدد.
3. **أزرار المهام:** 
   - **زر الاستعلام العادي:** يجلب معلومات البطاقات ببساطة.
   - **زر الخوارزمية الجشعة:** يُشغّل محرك التحسين ويعرض تفاصيل وخطوات الحل الذكي.

---

## 🛡️ 5. هندسة الحماية (Fallback System)
لمنع المتصفحات الحديثة من حجب ملف الـ JSON بسبب سياسة (CORS Policy) عند فتح الملف بنقرتين (file:///)، تم بناء نظام طوارئ:
- في حال فشل الـ `Fetch` المباشر، ينتقل النظام صامتاً لاستخدام نسخة الـ Knowledge Base المدمجة في ملف `fallback_kb.js`.
- **النتيجة:** المشروع يعمل بنسبة 100% وفي أي بيئة وبمجرد فتح `index.html`!

---

## 🚀 6. طريقة التشغيل (How to Run)
* **الطريقة السهلة (موصى بها للمناقشة):** فقط قم بالدخول للمجلد واضغط مرتين متتاليتين على ملف `index.html`، وسيعمل المشروع مباشرة بفضل نظام الـ Fallback.
* **طريقة الخادم المحلي (Local Server):** قم بفتح سطر الأوامر (Terminal) في مسار المشروع واكتب `python run_server.py`، سيقوم هذا السكربت بإنشاء خادم محلي وفتح المتصفح تلقائياً.
