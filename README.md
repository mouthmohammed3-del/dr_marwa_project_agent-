# 🎓 نظام الاستعلام الأكاديمي الذكي - مدرسة النجاح باليعر

**مقدم للدكتورة:** د. مروة  
**طبيعة التكليف:** بناء واجهات ويب ديناميكية تعتمد بالكامل على قاعدة معرفة (Knowledge Base) بتنسيق `JSON` واسترجاع البيانات عبر قوائم منسدلة (Dropdowns) ومربعات اختيار (Checkboxes).

---

## 📌 1. نبذة عامة عن المشروع
هذا المشروع عبارة عن تطبيق ويب تفاعلي صُمم ليكون دليلاً أكاديمياً متكاملاً لـ **"مدرسة النجاح باليعر"**. 
المشروع يعتمد هندسة معمارية خفيفة (Frontend-Only) تعتمد في تغذيتها بالبيانات على ملف **Knowledge Base (JSON)** حصراً، مما يحقق متطلبات التكليف باستبعاد استخدام قواعد البيانات التقليدية (SQL) أو حزم البيانات (Data Sets / CSV).

---

## 🎯 2. أهداف المشروع والتقنيات المستخدمة
تم بناء هذا النظام لإثبات القدرة على استخراج وتصفية البيانات الهرمية المعقدة وعرضها للمستخدم بشكل مبسط.

**التقنيات المستخدمة:**
* **`JSON` (JavaScript Object Notation):** لتمثيل قاعدة المعرفة (Knowledge Base) وتخزين البيانات بشكل هيكلي دلالي.
* **`HTML5 & CSS3`:** لبناء واجهات مستخدم احترافية، متجاوبة (Responsive)، وتجربة مستخدم (UX) سلسة.
* **`Vanilla JavaScript (ES6)`:** لمعالجة المنطق البرمجي (Logic)، جلب البيانات (Fetch API)، وبناء العناصر ديناميكياً في الـ DOM.

---

## 🗂️ 3. هيكلة قاعدة المعرفة (Knowledge Base Structure)
تم بناء ملف `kb.json` ليكون شاملاً ويغطي **12 سنة دراسية كاملة** (من الأول الأساسي حتى الثالث الثانوي). وتمت هيكلة البيانات كالتالي:
1. **Metadata:** بيانات وصفية عن النظام.
2. **Educational Stages (المراحل الدراسية):** 
   - الأساسية (أولية وعليا)
   - الإعدادية
   - الثانوية
3. **Grades (الصفوف):** كل مرحلة تحتوي على صفوفها الخاصة (مثال: الصف الأول الثانوي، الصف التاسع).
4. **Subjects (المواد والمعلمين):** يمتلك كل صف مصفوفة من المواد، حيث تحتوي كل مادة على:
   - `subject_name`: اسم المادة (مثال: الفيزياء، الرياضيات).
   - `teacher`: اسم المعلم المختص.
   - `book`: اسم الكتاب المقرر.

---

## ⚙️ 4. آلية عمل الواجهة (User Interface Logic)
تم تصميم الواجهة لتكون متسلسلة وتفاعلية:
1. **القائمة المنسدلة (Dropdown):** بمجرد تشغيل النظام، يقوم الـ JavaScript بقراءة الـ JSON وبناء الخيارات وتصنيفها في القائمة المنسدلة حسب المرحلة الدراسية.
2. **التوليد الديناميكي (Dynamic Checkboxes):** عند اختيار المستخدم لصف معين (مثال: الصف العاشر)، يقوم النظام بمسح واجهة الاختيارات وبناء `Checkboxes` جديدة لحظياً تتطابق مع مواد ذلك الصف فقط.
3. **الاستعلام وعرض النتائج:** عند تحديد المواد والضغط على زر الاستعلام، يقرأ النظام البيانات ويطبع بطاقات تفصيلية توضح (اسم المادة، اسم الأستاذ، والكتاب المقرر).

---

## 🛡️ 5. هندسة الحماية وتجاوز أخطاء المتصفحات (Fallback System)
من أبرز التحديات في تطوير تطبيقات الويب المحلية هو منع المتصفحات الحديثة لجلب ملفات الـ JSON (CORS Policy) عند فتح الملف بنقرتين (file:///). 

**لحل هذه المشكلة بذكاء، تم تطبيق هندسة (Fallback):**
* يحاول النظام أولاً جلب البيانات من `kb.json` برمجياً عبر الـ `Fetch API`.
* في حال اكتشف النظام أن المستخدم فتح الملف بدون خادم (Server)، يقوم فوراً وبشكل صامت بالانتقال واستخدام نسخة البيانات الاحتياطية المدمجة في `fallback_kb.js`. 
* **النتيجة:** المشروع يعمل بنسبة 100% وفي أي بيئة تشغيل، سواء على خادم محلي، أو بمجرد فتح ملف `index.html` بنقرتين مباشرين!

---

## 🚀 6. طريقة التشغيل (How to Run)
تم تصميم المشروع ليعمل بأبسط الطرق الممكنة:

* **الطريقة السهلة (موصى بها للمناقشة):** فقط قم بالدخول للمجلد واضغط مرتين متتاليتين على ملف `index.html`، وسيعمل المشروع مباشرة بفضل نظام الـ Fallback.
* **طريقة الخادم المحلي (Local Server):** قم بفتح سطر الأوامر (Terminal) في مسار المشروع واكتب `python run_server.py`، سيقوم هذا السكربت بإنشاء خادم محلي وفتح المتصفح تلقائياً.
